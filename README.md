# ConexãoPro Next 🚀

Rede Social Acadêmica do SENAI Barreto.

O ConexãoPro é uma plataforma criada para conectar alunos, professores e projetos em um único ambiente digital.

## Objetivos

- Comunicação entre alunos e professores
- Compartilhamento de projetos
- Divulgação de eventos e cursos
- Criação de portfólio acadêmico

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
